# JavaScript/Node.js Language Worker

This is a gRPC server that executes JavaScript/Node.js code for the Composer workflow engine.

## Installation

```bash
npm install
```

## Usage

```bash
# Set port (default: 50052)
PORT=50052 npm start
```

## Environment Variables

- `PORT` - gRPC server port (default: 50052)

## Development

```bash
npm run dev  # Run with watch mode
```
